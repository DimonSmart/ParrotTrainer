# IDD-0002 spec: Phrase audio recording

## Behavior

The owner can record a spoken training phrase. The app prioritizes obtaining playable audio and, where the device supports it, simultaneously transcribes the phrase. A successful recording always refers to audio containing actual samples; an empty or corrupted recording is not saved as a phrase recording.

If coordinated recording and transcription cannot start or produces unusable audio, the editor releases that session before using ordinary audio recording. For the remainder of that editor session, it uses ordinary recording without transcription so the owner can continue recording phrases. A transcription error alone does not disable coordinated recording when the audio is valid.

Leaving the phrase editor or interrupting a recording releases its microphone resources. The editor never records through more than one microphone service at a time, and restores the main microphone monitor after it closes.

## Acceptance criteria

- The owner can make consecutive recordings in one editor session without reopening it.
- A phrase is marked recorded only when its saved audio contains playable samples.
- When coordinated recording is unavailable or fails, ordinary recording remains available after coordinated resources are released.
- The editor informs the owner when audio could not be recorded, without presenting an empty file as success.
- A valid recording is retained if transcription fails, and the editor indicates that transcription was unavailable.

## Verification

- Exercise multiple consecutive start and stop cycles and confirm every saved recording has nonempty audio samples.
- Verify that a coordinated-recording start failure or unusable result falls back to ordinary recording after cleanup.
- Verify that cancellation on app backgrounding and closing the editor leaves the microphone available to the main monitor.
