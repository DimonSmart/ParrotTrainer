# IDD-0003 spec: Voice selection and preview

## Behavior

The owner can browse the text-to-speech voices installed on the device and select one or more voices for training. The voice list provides a text filter that matches a voice name or locale, so the owner can quickly narrow the installed voices by a language tag such as `ru`.

Speech-rate, pitch, and volume controls appear before the voice list. The owner can play a short sample through the system voice to check those speech settings. The owner can also play the same sample for an individual installed voice before selecting it.

## Acceptance criteria

- Typing text in the voice filter shows only voices whose name or locale contains that text, regardless of letter case.
- An empty filter shows every installed voice, and a filter with no matches clearly indicates that no voices were found.
- Speech-rate, pitch, and volume controls are available before the owner browses the voice list.
- The owner can play a short sample using the current speech settings without selecting a voice.
- The existing ability to select multiple voices and preview an individual voice remains available.

## Verification

- With installed voices of different locales, filter by a locale fragment such as `ru` and confirm that only matching voices remain visible; then verify the empty and no-match states.
- Change each speech setting and play the sample, confirming that the system voice uses the current settings.
- Preview an individual voice and confirm that it uses the same current speech settings.
